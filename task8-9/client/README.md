# Zen-Money — клиент

Фронтенд на чистом JS (ES-модули, классы), без сборки. Работает с сервером на `http://localhost:3001`.

## Структура

Код разбит на три ES-модуля (как требует задание). Всё обёрнуто в классы, глобальных переменных нет:
объекты создаются в `main.js` и получают зависимости через конструктор (DI), как на сервере.

| Файл | Класс | Роль |
|------|-------|------|
| `api.js` | `ApiClient`, `ApiError` | все запросы к серверу (`fetch` + `async/await`), разбор ошибок `{ "error": "..." }`; `fetch` передаётся в конструктор |
| `ui.js` | `UI` | вся работа с DOM: отрисовка, чтение значений форм, привязка событий; `document` передаётся в конструктор |
| `main.js` | `App` | точка входа: состояние, обработчики действий, клиентская валидация, настройки в `localStorage`; получает `ApiClient`, `UI` и `localStorage` через конструктор |
| `index.html`, `style.css` | — | разметка и стили (светлая/тёмная тема) |

## Запуск (сначала сервер, потом клиент)

1. Сервер:
   ```bash
   cd task8-9/server
   npm install
   npm start        # или: node server.js — порт 3001
   ```
   Файл `database.sqlite` создаётся автоматически при первом запуске,
   стартовые категории («Еда», «Транспорт», «Зарплата») добавляются, если таблица `categories` пустая.

2. Клиент: ES-модули не работают при открытии через `file://`, поэтому нужен http-сервер:
   - VS Code → расширение **Live Server** → «Open with Live Server» на `client/index.html`, или
   - `cd task8-9/client && npx serve .` (или `python -m http.server 5500`).

   Откройте выданный адрес (например, `http://127.0.0.1:5500`). CORS на сервере включён глобально.

## Как это соответствует заданию

- Фильтры (категория, тип, диапазон дат) отправляются как query-параметры
  `GET /transactions?type=expense&from=2026-01-01` — фильтрация выполняется в SQL (`WHERE`) на сервере, на клиенте `.filter()` не используется.
- Сводка «Доходы / Расходы / Баланс» считается на клиенте по загруженному списку (`App`).
- Ошибки сервера (400/404/500) и недоступность сервера показываются сообщением сверху (`App` → `UI.showMessage`).
- Клиентская валидация (сумма > 0, категория, дата, название категории) только ускоряет обратную связь — серверная валидация остаётся главной.
- В `localStorage` хранятся только настройки интерфейса: последние фильтры и тема.
